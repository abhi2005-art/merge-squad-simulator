      Cost per level 
      
      
      
      
      Every level merges at most n items and there are about log₂n levels, so the total is n × log₂n. This is the recursion-tree method.
      
    
      
    
      
      
      Master Theorem check
      
      
      T(n) = 2T(n/2) + Θ(n) has a = 2, b = 2 and f(n) = n. Since n^(log₂2) = n matches f(n), this is Case 2, so T(n) = Θ(n log n).
